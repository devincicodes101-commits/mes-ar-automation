Reminder Emails

Reminder Emails is where the letters live: the ones due today, every letter that has gone, where each tenant's bills stand, and the tenants who can only be written to by hand. The 9am run sends the letters on its own, so most days you come here to check, not to send.

The screen

The screen has five tabs. The number beside a tab is how many letters are in it.

The letters due today

The First reminder and Final notice tabs list the same letters the 9am run sends today. On a normal day the run has sent them by the time you look, and both lists are empty, as in figure 5.1. A letter stays on the list when it could not go, for example because no mailbox was connected. You can then send it from here.

Each row shows the tenant, the addresses the letter goes to, and the amount it asks for, which is the total of the bills on that billing date. Each row has two buttons.

  • Read and send opens the letter as the tenant will get it. You can change the subject or the wording for this one letter, then press Send this email.
  • Edit letter changes what the 9am run sends to this tenant for this bill (section 5.4).

To send the whole list at once, press Send all. A window lists every tenant, the addresses and the amount asked for. Press Send all again in that window to send them. They go in small batches with a short pause between, the same pace as the 9am run, and the button counts them as they go. If any are refused, the window stays open so you can see which.

Good to know

Sending a letter yourself counts the same as the 9am run sending it. The run will not send the same letter again for that bill.

Where each tenant stands

The All tenants tab shows every tenant's bills, one row per tenant per billing date, with the day each letter falls due and what has happened so far.

Editing one tenant's letter

Sometimes one tenant needs different wording, for example when an arrangement has been agreed. Edit letter changes what the 9am run sends to that tenant, for that bill only. Everyone else still gets MES's standard letter.

  1. Find the tenant on the All tenants tab, or on the First reminder or Final notice tab, and press Edit letter.
  2. Choose the letter at the top: First reminder or Final notice.
  3. Change the subject or the wording.
  4. Open the preview and read it through.
  5. Press Save for the automatic send. The tenant's row is then marked Edited.

To undo an edit, open the letter again and press Back to the standard wording.

Careful

An edit changes what a tenant is told about money, and it goes out without anyone pressing send. Read the preview before saving. If a word in double braces is misspelt, the system refuses to save and lists the ones it fills in, so a tenant never receives a letter with {{amont}} where the amount should be.

The Sent tab

The Sent tab lists every letter the system has sent, newest first. This is the place to look when a tenant asks whether their reminder went out.

A letter marked "not sent" in red was written but did not leave, usually because sending was off or the mailbox needed reconnecting. The Activity Log has the reason.

Tenants with no email address

The By hand tab is for tenants the system cannot email. Their letters are written on the same day as everyone else's, and you post them yourself from Outlook.

  1. On Due today, open a tenant's letter.
  2. Press Copy beside the subject and paste it into a new email in Outlook. Do the same for the letter.
  3. Send it from Outlook to the address you have for them.
  4. Back in the system, press I have sent this by hand. This records the letter against the tenant, so the system knows it went.

If you find their address, type it into the box at the bottom of the letter window. They then get their letters automatically like everyone else. To fill in many addresses at once, download the list, add the addresses in the Email Address column, and upload it as a contact list on Upload Reports.

What happens in the background

  • Who is due a letter today is worked out exactly as the 9am run works it out: each bill that reaches 23 days old today gets a first reminder, and each that reaches 37 days gets a final notice.
  • Several bills, one email. A tenant with several bills due the same letter on the same day gets one email asking for their combined total.
  • The amount in a letter is that billing date's total, not the tenant's whole balance. The letter does not list the invoices.
  • The date in a letter is the date of the report in use, and the deadline to pay is counted from it, so the letter never quotes a balance for a day it does not have.
  • Promises hold letters. A tenant who has promised to pay by a date that has not passed is left out.
  • Sent means sent. A letter counts as sent only once the mail server has accepted it. One that was refused is kept and marked "not sent", and stays on that day's list to be sent again.
