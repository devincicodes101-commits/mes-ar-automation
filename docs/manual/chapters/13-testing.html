How to test the system

Use these checks to confirm the system works before trusting it with real tenants, and again after any change to the system or its settings. Each test says what to do and what you should see. Tick the box when it matches. If it does not, write down what you saw and when, and send it to the system administrator.

Before you start

Testing must never reach a real tenant. Check all of these first.

  1. Sending is on test addresses only. On Settings, Mailbox, the label reads "Test addresses only". If it reads "Sending to real tenants", stop and ask the system administrator to switch it back.
  2. The test list holds only test inboxes. Check the Test addresses box on the same tab. This is the second check: a letter to any address not on the list is held back, whatever the contact list says.
  3. Use the test files kept with this manual in docs/manual/samples: a shortened AR report of 15 tenants, a contact list whose addresses are all test inboxes, and a file that is not a report.
  4. Have a login for each role: Admin, CSD Officer, Relationship Manager and Management.
  5. Note the report in use on Upload Reports before you start, so you can put it back.
Careful

Saving a test report replaces the report everyone sees, and a raised fee is real. Test on a day nobody else is working in the system, and upload the current NetSuite report again when you finish (test U10).

Signing in and roles

#Do thisYou should seePass
S1Sign in with a wrong password.You stay on the sign-in page, with a message under the boxes.
S2Sign in as Admin.Outstanding Balances. The menu has The cycle, Review and Admin, and your name and role are at the bottom.
S3Sign in as CSD Officer.The same menu without Settings and User Management.
S4Sign in as Relationship Manager.Only Outstanding Balances and Call List, showing only that manager's tenants. No email addresses anywhere.
S5As Relationship Manager, type the address of Settings into the browser.You are taken back to Outstanding Balances.
S6Sign in as Management.Outstanding Balances, Reports and Export and the Activity Log only. Nothing can be sent or changed.
S7Press the moon button, then press it again.The screens switch to dark and back to light.
S8Sign out.The sign-in page.

Uploading a report

#Do thisYou should seePass
U1Open Upload Reports.The Report in use box gives the month, the number of tenants and invoice lines, and the report date.
U2Choose not-a-report.csv as the AR report and press Read the file. "Nothing usable. Neither file could be read as an AR report." The checks say "Do not use this data", and there is no Use this report button.
U3Press Remove file. Choose the sample AR report and press Read the file. Billing month October 2026. The totals show 15 tenant accounts with 1 in credit, SGD 195,443.08 owed and 135 invoice lines.
U4Read Checks on this upload."Usable, but read these first", with "No contact list in this upload" among the warnings.
U5Add the sample contact list and press Read the file again.The contact list warning is gone and Can be emailed is above 0.
U6In Compared with the report of, open New bills.The new invoices, grouped by billing date. Dates other than the 15th are marked Ad hoc.
U7Go to another screen and come back to Upload Reports.The files and the comparison are still there. Nothing was saved.
U8Press Use this report."Saved. Everyone signed in now sees this report." Report in use and the menu show the new month.
U9Open the Activity Log."Uploaded a report", with your name, the file and the time.
U10Upload the current NetSuite report and press Use this report.The real report is in use again. Calls and promises from before are still there.

Outstanding Balances

#Do thisYou should seePass
B1Open Outstanding Balances.The four totals, and tenants listed most overdue first, with the report date under Tenants.
B2Type part of a tenant's name in the search box.Only matching tenants.
B3Press Overdue, then All.The count on each matches the list.
B4Press Aging columns, then click the 90 days heading twice.The list sorts by that column, then the other way round.
B5Press + on a row.That tenant's invoice lines open under the row.
B6Open Show charge types and billing runs.The total at the foot of By charge type equals Total owed at the top.
B7On a test tenant with no email, press No email, add one, type a test inbox and press Enter."Email saved". The tenant leaves the By hand list on Reminder Emails.
B8Click a tenant's name.Their page: totals, everything done for them, and every charge line.

Reminder Emails

#Do thisYou should seePass
R1Open Reminder Emails.Five tabs. The counts on First reminder and Final notice match their lists.
R2Open All tenants. Pick a tenant billed on the 15th of last month.First reminder 23 days after billing and final notice 37 days after, as in Settings.
R3Click one of the Where they stand filters.Only those bills, and the count matches.
R4Press Edit letter on a test tenant. Change a sentence, open the preview, and press Save for the automatic send.The preview shows the change with the amount filled in. The row is marked Edited.
R5Edit the letter again and change {{amount}} to {{amont}}.Save stays greyed out, and a message lists the words it fills in.
R6Press Back to the standard wording.The Edited mark is gone.
R7On a day a letter is due to a test tenant, open First reminder and press Read and send, then Send this email.The letter arrives in the test inbox, from MES Group AR, asking for that billing date's total. It moves to the Sent tab.
R8Open the Sent tab and click a letter.The letter exactly as sent, with who it went to and when.
R9Open By hand and press Download the list.A spreadsheet of the tenants with no address.
R10On a day a by-hand letter is due, open it, press Copy, then I have sent this by hand.The letter is copied. The tenant moves to Sent by hand with today's date.

The 9am run

#Do thisYou should seePass
N1The morning after setting up a test tenant whose bill is 23 days old, open Activity Log, 9am runs.A row for today saying how many first reminders were written and sent.
N2Check the test inbox.The first reminder arrived around 9am.
N3Look for real tenants in that row.Any letters to addresses not on the test list are "held back" with the reason test mode.
N4Open Reminder Emails, All tenants, for that test tenant."First reminder sent" with today's date.
N5If Needs attention shows a missed morning, press its button and confirm.The missed letters go, and tenants who already had theirs are skipped.

C2Press Log this call on a test tenant and try to save without choosing what happened.It will not save until an outcome is chosen.

C10Open Reminder Emails, All tenants, for that tenant."Promised to pay by" the date. No letter goes before it.

Late Payment Fees

#Do thisYou should seePass
F1Open Late Payment Fees.Accounts to be charged times SGD 100 equals Fees to raise, less any already charged this month.
F2Find a tenant whose only unpaid bill is less than 14 days past due.They are not on the list.
F3Look at Left out: on GIRO.Each tenant there has a Rejected GIRO Fee in the report.
F4Press Download the listing.A spreadsheet of the fees, including the GIRO tenants left out.
F5Press Review and raise, then Cancel.The window shows the count and total, and nothing is raised.
F6After the 16th, open Activity Log, 9am runs.A 16th row, "Charged" with the tenants named. Late Payment Fees now says they have been charged this month.

Settings

#Do thisYou should seePass
G1Open Settings, Mailbox."Test addresses only". One mailbox marked "Sends the 9am reminders", and no red problem line.
G2Send a test to a test inbox."Test sent", and it arrives from MES Group AR.
G3Send a test to an address that is not a test inbox."Nothing was sent", with the reason. Nothing arrives.
G3aAdd your own address to Test addresses, send a test to it, then remove it and send another.The first arrives. The second says "Nothing was sent", not on the test list. Both changes to the list are in the Activity Log.
G3bOn a tenant used for testing, type an address that is not on the test list, and send that tenant's letter from Reminder Emails on a day one is due.The letter is held back and marked "not sent", with the reason. Nothing arrives at that address. Remove the address afterwards.
G4On Reminder timing, type 30 as the first reminder without saving.The worked example changes. Change it back.
G5Type a final notice smaller than the first reminder."Cannot save".
G6Change a setting, save, then change it back and save.Two entries in the Activity Log, each with your name.
G7On Report recipients, type a test address for one recipient and press Enter."Ready" beside it, and the same address on Reports and Export.
G8Open Charge types.The rules, read only, ending with Other Charges.
