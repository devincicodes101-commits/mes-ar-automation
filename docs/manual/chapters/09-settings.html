Settings

Settings holds the choices the 9am run works to: the mailbox letters go out from, when reminders are due, how the late fee is worked out, and who reports are emailed to. Only an Admin or Super Admin can open it. A saved change applies from the next 9am run, and every change is recorded in the Activity Log.

The five tabs

TabWhat it holds
MailboxThe mailboxes letters can be sent from and which one is active, whether sending is switched on, a test letter, and the test list.
Reminder timingHow many days after billing the first reminder and the final notice go, and three choices about how they are counted.
Fees and reportsWhen the S$100 late fee applies, the regular billing day, and what to do when the report is old.
Report recipientsThe email addresses reports are sent to.
Charge typesThe rules that sort each charge into a type. Read only.

The Mailbox tab

Settings opens on Mailbox. It holds the list of mailboxes, the one letters go out from, and the test list. It also answers the question "why did nobody get the reminder?" without anyone having to guess.

Set this up first

The system is handed over with no mailbox connected and an empty test list, so nothing can be sent until MES set both up. Before any testing, connect MES's mailbox (section 9.3), then put the addresses you will test with on the test list (section 9.5). Chapter 13 starts with these steps.

Once mailboxes are connected, each row has its own buttons:

  • Make active makes that mailbox the one every letter goes out from. Only one is active at a time.
  • Remove takes a mailbox off the list, and it can no longer send. The active mailbox cannot be removed while there are others: make another one active first.
  • Reconnect appears when a mailbox has stopped working, with the reason in red (section 9.7).

Connecting MES's mailbox

Letters go out from a real mailbox, and tenants' replies come back to it.

Which account to connect

Connect a Microsoft 365 work mailbox, such as the AR team's address, rather than one person's or a personal Outlook.com account. Replies then reach the whole team, nothing breaks when someone leaves, and Microsoft is far less likely to lock the account as suspected spam, which it does to personal accounts that send many letters. It must be a mailbox someone can sign in to with a password. A shared mailbox that nobody signs in to cannot be connected.

  1. Sign in to MES AR Automation with an Admin login.
  2. Open Settings. On the Mailbox tab, press Connect Outlook.
  3. Microsoft's sign-in page opens. Sign in as the mailbox you want letters to come from, for example the AR team's address. This does not have to be your own account.
  4. Microsoft asks you to allow MES AR Automation to sign you in and read your profile, send mail as you, and keep access to these. Press Accept. The system can send mail only. It cannot read the mailbox.
  5. You are brought back to Settings. The notice "Connected" names the address, and the mailbox appears in the list.
  6. The first mailbox connected is made active straight away. Connecting an address that is already on the list refreshes its row rather than adding a second one.
If Microsoft says "Need admin approval"

Some companies let only their IT administrator allow new apps. If that screen appears, ask MES's Microsoft 365 administrator to approve MES AR Automation for the organisation, in the Entra admin centre under Enterprise applications. Then try again.

Connecting Gmail instead

Connect Gmail works the same way. Google may show "Google hasn't verified this app": press Advanced, then Go to mes-ar-automation.vercel.app, and carry on. If Google says "Access blocked" with Error 403: access_denied, the system administrator must first add that Gmail address as a tester, or publish the app (chapter 14).

Which mailbox letters come from

  • Every letter comes from the active mailbox: the 9am run's letters, letters sent from Reminder Emails, promise confirmations and emailed reports.
  • Replies come back to the active mailbox.
  • Tenants see the sender's name as MES Group AR.
  • To change it, press Make active on another mailbox. The notice says it "is now the active mailbox", and the next letter goes from it.

The test list

The Test addresses box on the Mailbox tab is a second safety check for testing. While sending is set to test addresses only, a letter goes out only if every address it is going to is on this list. Any other letter is written, held back and recorded with the reason "not on the test list". So even if a real tenant's address finds its way into the system during a test, that tenant is never written to.

The list starts empty. Before testing, add the inboxes you will test with, such as a few MES staff addresses. Use only inboxes someone at MES can open, so every test letter can be checked.

Every change to the list is recorded in the Activity Log, with who made it. If the list is empty while testing, nothing can be sent at all. Only an Admin or Super Admin can see or change it.

Sending a test letter

  1. Type an address in the Send a test letter box on the Mailbox tab.
  2. Press Send me a test.
  3. "Test sent" means it left, and names the mailbox it came from. "Nothing was sent" gives the reason. For example, while sending is set to test addresses only, an address that is not on the test list is refused.

When a mailbox needs reconnecting

Microsoft or Google can stop accepting a connection after a password change, when access is removed, or after a long time unused. The mailbox's row then shows the reason in red, and Reminder Emails says the active mailbox needs reconnecting. Press Reconnect on its row and sign in again. Nothing else changes.

If the reason says Microsoft has locked the account as suspected spam, reconnecting will not help until the account is unlocked. Its owner signs in at outlook.com and follows Microsoft's steps to verify the account, then presses Reconnect.

Set outside this screen

Two things are set once by the system administrator in the hosting settings, not on this tab: the sending mode (off, test addresses only, or real tenants), and the connection to Microsoft or Google that makes Connect Outlook and Connect Gmail work. Keeping the mode outside the system means switching to real tenants is always a deliberate step. If no connection is set up, the tab says "Mailbox sign-in has not been set up yet". Chapter 14 covers both.

Reminder timing

The final notice must come after the first reminder. If it does not, the screen says "Cannot save".

Fees and reports

Report recipients

The addresses reports are emailed to: the AR team, CSD, management, and each relationship manager named in the report. Type an address and press Enter, or click elsewhere, to save it. The label beside it changes from "No address" to "Ready". Leave a box empty for someone who should not receive reports.

Charge types

Each charge description in the AR report is sorted into a type, such as Occupancy Fee, VAT or Late Payment Fee, by the rules on this tab. They are checked in order, and the first that matches wins. Anything that matches none is Other Charges, and is listed by name after every upload so a new wording is seen straight away. The rules are read only. To change one, ask the system administrator.

What happens in the background

  • One copy of each setting is kept centrally. Every screen and the 9am run read the same one, so a change on one computer applies everywhere.
  • Changes are recorded. Each save writes an entry in the Activity Log with who changed what.
  • Changes apply forward. A change to timing affects letters from the next 9am run. Letters already sent are not sent again.
  • Until timing is first saved, the 9am run uses the standard 23 and 37 days, and the tab says "Built-in default".
