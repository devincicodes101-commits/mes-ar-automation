Going live checklist

These are the steps to move from testing to sending real letters to real tenants, in order. Some are done in the system by an MES Admin. Others are done once by the system administrator in the hosting settings, and are marked as such. Do not switch sending on (step 5.1) until every step before it is done.

Before anything else

#StepWhoDone
1.1Set sending to "Nothing is sent" while everything else is set up.System administrator
1.2Make sure the Microsoft connection is in place, so Sign in with Microsoft works. Settings, Mailbox must not say "Microsoft sign in has not been set up".System administrator
1.3If MES's Microsoft 365 only lets IT approve new apps, have MES's IT administrator approve MES AR Automation for the organisation.MES IT

Clearing the test data

#StepWhoDone
2.1Clear the test letters, calls, promises, fees, edited letters and 9am run history, so the first live month starts clean.System administrator
2.2Switch off or remove the test logins on User Management.MES Admin
2.3Create a login for each person at MES, with the right role. Relationship Managers need their manager chosen (chapter 10).MES Admin

Connecting MES's mailbox

#StepWhoDone
3.1Sign in, open Settings, Mailbox, press Sign in with Microsoft, and sign in as the AR team mailbox (section 9.3).MES Admin
3.2Press Use for 9am reminders on that mailbox, so it is marked "Sends the 9am reminders".MES Admin
3.3Press Disconnect on every test mailbox.MES Admin
3.4Set sending to "Test addresses only", with a few MES staff addresses as the test list.System administrator
3.5Send a test to one of those addresses and reply to it. The test arrives from MES Group AR, and the reply reaches the AR mailbox.MES Admin

Loading the real data

#StepWhoDone
4.1Upload the current AR report from NetSuite and the real client contact list, read the checks, and press Use this report (chapter 3).MES Admin or CSD
4.2Fill in every address on Settings, Report recipients.MES Admin
4.3Check Reminder timing and Fees and reports hold the numbers MES wants.MES Admin
4.4Open Reminder Emails, All tenants, and check the reminder dates of a few tenants you know.MES Admin or CSD

Switching sending on

#StepWhoDone
5.1Set sending to "Sending to real tenants".System administrator
5.2Check Settings, Mailbox reads "Sending to real tenants", with the AR mailbox as the sender and no problem line.MES Admin
5.3The next morning, after 9am, open Activity Log, 9am runs, and Reminder Emails, Sent. The letters due that day went, from the AR mailbox.MES Admin or CSD

The first live month

  • Check the 9am runs tab each morning for the first week, and Needs attention every day.
  • Watch the AR mailbox for replies and bounced emails. A bounce usually means an address in the contact list is wrong: correct it and upload the list again.
  • On the 16th, check the fees raised on Late Payment Fees and download the listing for the AR team.
  • Upload a new report after each billing run, as in chapter 3.
For the system administrator

The sending mode is the hosting setting MAIL_MODE: off, allowed (test addresses only, listed in MAIL_ALLOWLIST) or everyone. The Microsoft connection is MICROSOFT_CLIENT_ID, MICROSOFT_CLIENT_SECRET and MICROSOFT_TENANT, with https://mes-ar-automation.vercel.app/api/mail/microsoft/callback registered as the redirect address. A change to any of these takes effect after the site is redeployed.
