Upload Reports

Everything the system knows about who owes what comes from the AR report you upload here. Upload a new one after each billing run and whenever payments have been posted in NetSuite. Every screen, and the next 9am run, then works from it.

The two files

FileWhere it comes fromHow often
AR report
required		 NetSuite, Finance AR Download, from the Detailed AR report. The Custom A/R Aging Detail export also works. Save it as Excel and do not change it. After each billing run, and when payments are posted. At least once a month.
Client contact list
optional		 MES's contact workbook. It needs a column headed Email Address next to each tenant's account code. Excel or CSV. Only when addresses change. The last one uploaded is kept.

The screen

Open Upload Reports, the first item in the menu. The top of the screen shows which report every screen is using now. Below it are the three things to fill in.

Good to know

Choosing the wrong file does no harm until you press Use this report. Even after that, you can upload the right file and it replaces the wrong one. Calls, promises and addresses typed in by hand are always kept.

Reading the file

  1. Click the AR report box and choose the file exported from NetSuite. Its name appears in the box. To change your mind, press Remove file.
  2. If the addresses have changed, choose the contact list in the second box.
  3. Press Read the file. A large report takes a few seconds.
  4. Check the billing month. The system suggests the month most tenants were last billed in, and says why, for example "7 of 15 tenants were last billed in October 2026".
Careful

The billing month is a label for the month the report belongs to. It does not change any billing date, because every charge carries its own. A wrong month files the figures under the wrong month, and fees and reminders are counted against it.

Checking what was found

The system lists what it read from the file and anything worth a second look. Read the checks before saving.

The warnings you are most likely to see:

WarningWhat it means
No contact list in this uploadNot a problem if addresses were loaded before, because they are kept. Without any, no reminder can be emailed and every tenant goes to the By hand list.
No "Transaction Type" columnThe export is missing a column, so credit notes cannot be told apart from invoices. Export again from the Detailed AR report.
No "Categories" columnCharge types are worked out from the description alone, which is less reliable.
No "Status" columnEvery tenant is treated as still renting.
A file could not be read at allIt is not an AR report or a contact list. Nothing from it is used, and there is no Use this report button.

Comparing with the report in use

Before you save, the system compares the new file with the report every screen is using. This is the quickest way to spot the wrong file.

LineMeans
Paid in full, no longer in the reportThe tenant was in the old report and is not in the new one. The system treats them as paid, so no more letters or calls.
Paid part, balance went downStill owing, but less.
Owe more, balance went upNew charges since the last report.
New tenantsIn the new report only.
New billsInvoices not in the old report, grouped by billing date. Dates other than the 15th are marked Ad hoc.
Total owedThe old total, then the new one.
If the comparison looks wrong

If almost every tenant shows as paid in full, or the new report is older than the one in use, you have probably chosen the wrong file or a partial export, and the screen warns you. Do not press Use this report. Choose the right file and read it again.

Saving

Press Use this report. The screen confirms "Saved. Everyone signed in now sees this report." The Report in use box changes to the new report, and the upload is recorded in the Activity Log as "Uploaded a report", with your name.

If you leave the screen before saving, the file and the comparison are kept until you come back, as long as you do not refresh the browser.

What happens in the background

  • Billing dates start the clocks. Each invoice line's Date is its billing date. The lines are grouped by tenant and billing date. Each group gets its own first reminder 23 days later and its own final notice 37 days later, and the next 9am run picks them up.
  • Due dates come from the report. If a group's lines carry one due date, that date is used. If not, the due date is 14 days after billing. The late fee counts from the due date.
  • Tenants who have gone have paid. They drop off Reminder Emails, the Call List and the fee list, and their promises to pay are marked "Paid, no longer owing".
  • Charges are sorted by type from their description, using the rules under Settings, Charge types. A tenant with a Rejected GIRO Fee line is treated as paying by GIRO and is not charged the late fee.
  • Addresses are matched by account code. A contact list adds addresses to the ones already held; it never removes any. The NetSuite Finance AR Download carries tenants' own addresses in its Contact Details tab, and those are read too. Addresses typed in by hand are kept.
  • A corrected export replaces, it does not add. Saving a report with the same report date as an earlier one replaces that day's figures.
  • The report's age is watched. If no newer report has been saved for more than 16 days, the 9am run still runs and the Activity Log shows a warning.
