Activity Log and the 9am runs

The Activity Log records everything that has been done, by a person or by the 9am run, with who did it and when. Nothing in it can be edited or deleted. Its second tab shows what each morning's run did, and anything that needs a hand is shown at the top.

Everything that has been done

Admin entries include uploading a report, changing a setting or the report recipients, adding or switching off a login, and sending a report. Entries are newest first, and the number at the top says how many there are in all.

Needs attention

When a 9am run has missed something, a Needs attention box appears above the log. Each item says what was missed and has a button to put it right.

It saysPress

Each button asks you to confirm first and says what it will do. These send real letters to tenants and raise real fees. Tenants who already had their letter are skipped, and no fee is charged twice.

What happens in the background

  • The log is permanent. Entries can be added but never changed or deleted, by anyone.
  • The 9am run starts by itself at 9am Singapore time. If it has more to send than fits in one go, follow-up runs at 10am, 11am and noon carry on from where it stopped.
  • Running a day twice is safe. Letters already sent are skipped and fees already raised are not raised again.
  • Management can read the log, and so can CSD officers. Relationship Managers cannot.
