4 commands

If any of these fail, stop. The manual tests below will be misleading.

A1

Run npm run test:pipeline

You do

  1. Open a terminal in the project folder
  2. Run the command
  3. Wait about 5 seconds

It does

  1. Prints one line per check, each starting PASS
  2. Ends with 184 PASS and ALL CHECKS PASS
  3. Exits with code 0

184 facts about the real export — the aging formula, 1FM detection, the GIRO split, both letters. The one that matters most: our total matches MES’s own customer subtotals to the cent.

A2

It does

  1. Ends with 109 PASS
  2. Prints the charge-type rules in order, each with the wording it matches

Every charge-type rule against every description MES has ever sent. Occupancy Fee alone is most of the money, so a rule moving is a serious change.

B3

A wrong password is refused, and says nothing useful

You do

  1. On /login, type admin@mesgroup.com
  2. Type wrongpassword
  3. Press Sign in
  4. Then try nobody@mesgroup.com with any password

It does

  1. Button becomes Checking with a spinner and goes disabled — a second click does nothing
  2. After roughly half a second the spinner stops
  3. A red-bordered box appears: That username and password do not match.
  4. The Password field is emptied. The Email field keeps what you typed
  5. You stay on /login
  6. The message for the unknown user is identical, character for character

A different message would tell an attacker which accounts are real. Both paths also take the same time, so absence cannot be detected by how fast it fails.

The monthly cycle, in order

browser

This is the sequence MES actually runs. Do these in order and the system reads as one process rather than nine screens.

E1

The 7th — who a reminder can reach

You do

  1. Open Reminder Emails
  2. Look at the first reminder section

It does

  1. 186 tenants are in scope — everyone with a balance, excluding those who have moved out
  2. 5 can actually be sent
  3. 181 are blocked, and each one is named with the reason “no email address”
  4. The blocked list is sorted largest balance first

A tenant with no address is never silently skipped. “Sent to 5” without saying 181 failed would be a lie by omission.

E2

The first reminder letter, merged

You do

  1. Open the draft for AVR ENGINEERING PTE. LTD.
  2. Read it in full

It does

  1. “As of today, 17th August 2026” — ordinal, from the report date
  2. “the outstanding amount stands at $27,678.58”
  3. “settle your outstanding dues latest by 23 August 2026” — plain, not ordinal, and 6 days out
  4. Mentions the $100 admin fee and the $50 cheque fee
  5. Carries DBS 011-901192-0 and PayNow UEN 200412284W
  6. Signed Jacqueline, Credit Control Officer
  7. No {{placeholder}} is left anywhere in the text

Two different date formats in one letter, because that is how MES wrote it. Both are reproduced rather than unified.

E3

The 21st — the final notice escalates

You do

  1. Switch to the final notice for the same tenant
  2. Compare it to the first

It does

  1. Dated 31 August 26 — short year, a third format
  2. Gives 7 September 26 to pay — +7 days, not 6
  3. Opens with “Despite our reminders”
  4. Cites the Employment of Foreign Manpower (Work Passes) Regulations 2012
  5. Raises disruption of our services and all available legal options
  6. Drops the cheque-fee paragraph entirely

If the final notice reads like the first, the template is wrong. This is a legal escalation, not a reminder.

G4

You do

It does

  1. 0 lines
  2. A note says no parking line appears anywhere in this export

The rule is built from MES’s earlier wording and has never matched real data. It will stay untested until a real parking line arrives.

Nothing is ever actually emailed

There is no mail transport in this build — no server, no credential, no address to configure. “Send” renders the letter, records it, and stops. These letters chase money and cite employment law; a prototype that could accidentally send one is a prototype that will.
